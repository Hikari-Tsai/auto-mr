# Auto MR Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a scheduled TypeScript GitHub Actions service that promotes configured branches through idempotent pull requests and merges them only when GitHub permits.

**Architecture:** A validated YAML file produces normalized project definitions. A promotion state machine talks through a narrow GitHub client interface, enabling deterministic unit tests; the CLI supplies the Octokit adapter and renders a GitHub Actions summary.

**Tech Stack:** Node.js 24, TypeScript 5, Octokit REST/GraphQL, Zod, YAML, Vitest, GitHub Actions

**Spec:** `docs/superpowers/specs/2026-09-04-auto-mr-design.md`

## Global Constraints

- Run every two hours at minute 17 and support manual dispatch.
- Use `AUTO_MR_TOKEN`; never print or persist its value.
- Never bypass or modify target repository protections.
- Reuse an open PR for the configured branch pair.
- Treat pending checks and reviews as successful waiting states.
- Continue after per-project failures and fail the overall command afterward.
